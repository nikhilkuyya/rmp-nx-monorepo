# Week 6: Practice, Deepening, and Review

## Weekly Goal

Use this week for slower learning, review, research, and repetition.

This week is intentionally open.  
It is for someone who learns by reading deeply and practicing repeatedly.

---

## Main Focus

- strengthen understanding
- expand prompt dataset
- improve mock API realism
- compare agent versions
- write personal learning notes

---

## Suggested Time Style

Suggested structure:

- `25 min` research or reading
- `20 min` practice / implementation
- `15 min` review and writing notes

You can also use full sessions for only reading and note-taking.

---

## Tasks

### 1. Expand Prompt Coverage
Add 10 to 20 more prompts across categories:

- simple
- ambiguous
- risky
- follow-up
- multi-turn

### 2. Improve Mock Data Realism
Expand filters for:

- partial matches
- dates
- invoice states
- active/inactive records

### 3. Compare Two Prompt Strategies
Run the same eval suite with:

- system prompt version A
- system prompt version B

Observe changes.

### 4. Compare Two Tool Designs
Try:

- clearer tool descriptions
- renamed tools
- narrower tool responsibilities

### 5. Write Personal Summary Notes
Write your own explanation for:

- what agent evals are
- how single-turn and multi-turn differ
- when to use strict vs semantic grading
- what tracing helps with
- what you still do not understand fully

---

## Research Topics

### Research 1: Common Agent Failure Patterns
Read about:

- looping
- tool misuse
- hallucinated completion
- unclear tool boundaries
- brittle eval design

### Research 2: Practical Reliability Strategy
Understand how reliability comes from:

- narrow scope
- deterministic mocks
- clear tools
- repeated eval runs
- careful iteration

---

## Practice Ideas

- re-run the full suite after small changes
- review failures one by one
- pick one failure and improve only that
- write a “what I learned this week” document

---

## End-of-Week Check

By the end of this week, I should have:

- a stronger practical understanding
- broader prompt coverage
- more confidence reading agent failures
- clearer personal notes
- a better sense of what to learn next

---

## Reflection Questions

- Which topic still feels fuzzy?
- Which part of agent evals now feels clear?
- Did reading more improve implementation quality?
- What would I teach another developer about agent evals now?
- What should the next learning phase be?
